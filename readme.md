# 💸 Expense Tracker

A simple and elegant React application to track your daily expenses. Built with Vite for fast development and localStorage for data persistence.

---

## 🚀 Features

- ✅ View a table of all your expenses
- ➕ Add a new expense (name, description, amount)
- 🔍 Filter expenses using a search bar
- 💾 Data is saved in `localStorage` and persists across page refresh
- 🧭 Clean and responsive layout using plain CSS
- 📌 Sticky table header for better UX with large datasets
